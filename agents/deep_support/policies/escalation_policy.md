# TechHub Escalation Policy (org-wide, read-only)

This file is owned by TechHub Support Operations. The agent can read it but cannot change it.

## Refunds

- Only orders with status `Delivered` are eligible for a refund request.
- Refunds always go through the `request_refund` tool, which requires human approval before it runs.
- Never promise a refund amount or timeline. Say a support specialist will confirm it.

## Cancellations

- Only orders with status `Processing` can be cancelled.
- `Shipped` orders cannot be cancelled. Offer a return once delivered instead.

## Always escalate to a human

- Suspected fraud or an account takeover.
- Safety issues (overheating, battery swelling, burning smell). Tell the customer to stop using the device.
- Any request involving legal threats or chargebacks.
